# About Tactiq

**AI meeting notes for people, teams, and agents.**

A company's freshest knowledge lives in its meetings — and evaporates when the conversation ends. Tactiq captures it and puts it to work:

- live transcripts and instant AI summaries for the person, across Google Meet, Zoom, and Microsoft Teams — in the browser, no bot joining the call
- shared, permissioned memory the team can search — with AI workflows that push decisions and actions into the tools where work happens
- meeting context your agents can pull from, with sources

Over 1 million people and 10,000+ companies use Tactiq.
- Website: [tactiq.io](https://tactiq.io)

## For agents

Tactiq is a verified connector in Claude's directory. The same MCP server works with Cursor, Claude Code, ChatGPT, and any other MCP client.

- Claude connector: [tactiq.io/claude](https://tactiq.io/claude)

- MCP server: `https://mcp.tactiq.io`

Ask for a quote and the answer comes with its source: who said it, in which meeting, word for word. Access follows the signed-in Tactiq user — the connector adds no new permissions.
